# Lev & Fit

Cardápio digital e pedidos da Lev & Fit (marmitas congeladas, Grande Florianópolis).

## Rodar

1. Crie o arquivo `.env` (copie o `.env.example`) com a URL e a chave publishable do seu Supabase.
2. `npm install`
3. `npm run dev` e abra http://localhost:3000 (painel: http://localhost:3000/#/admin)

Banco novo: rode `supabase/instalar.sql` no SQL Editor do Supabase. Detalhes em `CLAUDE.md`.
